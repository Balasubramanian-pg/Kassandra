# Normalization Agent Specification

## Responsibilities
1. Load normalization tables from `vault/99 - System/Taxonomy.md`.
2. Standardize company names, job titles, and work locations.
3. Canonicalize variant technology and skill names (e.g. `PowerBI` -> `Power BI`, `MS SQL` -> `Microsoft SQL Server`).
4. Update frontmatter metadata with canonical nomenclature to ensure accurate indexing.
