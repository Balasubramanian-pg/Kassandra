# Healthcare MDM

## Overview

A central database system consolidating patient, practitioner, and facility data across multiple legacy clinics to establish a single source of truth.

## Evidence & Demonstrated Capabilities

- Designed the star-schema data warehouse model using [[SQL]] in Snowflake.
- Formulated the analytical dashboard in [[Power BI]] to monitor data quality scorecards.
- Implemented Python data deduplication scripts utilizing record linkage algorithms.
